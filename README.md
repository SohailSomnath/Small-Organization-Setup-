# Small-Organization-Setup-
Designed and configured a small office topology using a Cisco 2811 router, four Cisco 2960 switches, six PCs and a server. Added an interface module to the router to support the required network interfaces.

What I practised

Planned and manually assigned IP addresses across four subnets.

Configured static routes and verified end-to-end reachability with ping and TTL values.

Troubleshot connectivity by checking cabling, interface status and addressing.
